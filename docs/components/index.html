Headless media UI

@media/media-ui-react and @media/media-ui-native do not fetch data, import an SDK, or ship a design system. The application supplies media, callbacks, markup, and CSS.

React grid

const grid = useMediaGrid({ hasMore, loading, onLoadMore });
<section {...grid.getGridProps()}>
  {items.map(item => <article {...grid.getItemProps()}>...</article>)}
  <div {...grid.getLoadMoreSentinelProps()} />
</section>

MediaGrid is an optional unstyled renderer around the same behaviour. Apply your own grid layout with style or className.

Lightbox and reels

useLightbox provides dialog and backdrop prop getters; the Lightbox renderer also handles Escape and focus restoration. useReelSwiper detects the active vertical reel through IntersectionObserver. Connect its active-item callback to the wrapper’s view event in the app.

React Native

The native prop getters adapt to FlatList (onEndReached, paging, viewability) and Modal (visible, onRequestClose), while leaving all presentation to the consuming mobile app.
