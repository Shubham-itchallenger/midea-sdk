Media SDK

@media/media-core is framework-independent. Configure it once; its cache, events, and typed Pexels mapping remain outside UI code.

Core client

import { createMediaClient } from "@media/media-core";
const media = createMediaClient({ apiKey });
const result = await media.search({ query: "forest", page: 1, perPage: 20 });

The client exposes search, curated, getPhoto, getVideo, trackView, trackDownload, onView, and onDownload. Searches and single-item fetches are memory-cached. Invalid queries, missing keys, and API failures throw typed MediaError values.

React and React Native

const { data, loading, error } = useMediaSearch({ query, page, perPage: 20 });
const media = useMedia();
media.trackView(asset.id);

Mount MediaProvider at the app root. Never import the core in the app and never construct a client during render. Subscribe to events inside an effect and return the unsubscription cleanup.
