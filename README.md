# Media SDK

A TypeScript media SDK built with React, Vite, and the Pexels API.

## Project Structure

- `@media/media-core` - Core media client, Pexels integration, caching, types, and events.
- `@media/media-react` - React integration and hooks.
- `@media/media-ui-react` - React UI components such as MediaGrid, Lightbox, and VideoPlayer.
- `apps/web` - Demo application.

## Requirements

- Node.js
- npm
- Pexels API key
