# Headless Media SDK

A small Pexels-powered media ecosystem with strict dependency boundaries:

```text
web app → media-react → media-core
web app → media-ui-react
React Native app → media-native → media-core
React Native app → media-ui-native
```

`media-core` is portable TypeScript: it owns Pexels requests, API-key validation, typed mapping, memory caching, and `view` / `download` events. Its default event listeners log activity, while applications may subscribe independently.

The React and React Native wrappers only adapt the core client to provider and hook idioms. The UI packages are deliberately independent: they accept data and callbacks, ship no styles, and know nothing about Pexels or the SDK.

## Packages

- `@media/media-core`: `createMediaClient`, search, curated photos, item fetches, cache, events.
- `@media/media-react`: `MediaProvider`, `useMedia`, `useMediaSearch`.
- `@media/media-native`: matching provider/hooks for React Native.
- `@media/media-ui-react`: headless grid, lightbox, and vertical reel behaviour plus optional unstyled render components.
- `@media/media-ui-native`: FlatList/Modal-oriented prop getters for grid, lightbox, and paging reels.
- `apps/web`: the only package that wires the React wrapper to web UI components.

## Run the demo

```bash
npm install
set VITE_PEXELS_API_KEY=your_key
npm run build
cd apps/web
npm run dev
```

Use a `.env.local` file for Vite in normal development:

```text
VITE_PEXELS_API_KEY=your_key
```

The browser necessarily receives this key to call Pexels directly. Do not commit it. A production app should use a server-side proxy if the key must remain private.

The initial package scaffold was AI-assisted; the architecture, dependency boundaries, API choices, and verification were reviewed and refined manually.

## Deployment and submission

The repository includes a Vercel configuration for the web app and a GitHub Pages workflow that deploys the SDK and component docs. Follow [the submission checklist](docs/SUBMISSION.md) after pushing the repository. Public deployment and shared-chat links must be generated by the repository/account owner.

## Scope notes

The web demo implements search, photo preview/download tracking, and video reels. Native packages expose the corresponding adapter and headless behaviours but intentionally do not include a sample mobile app or native video renderer; those choices belong to the React Native consumer.
